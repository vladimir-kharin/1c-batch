# 1c-batch

Навык ([Agent Skill](https://agentskills.io)) для AI-агентов — автоматизация пакетных операций с платформой 1С:Предприятие 8. Набор PowerShell-скриптов (с запасными bat-версиями) для сборки обработок, управления конфигурацией и расширениями, запуска 1С — всё без ручного вмешательства.

<details>
<summary>Что такое Agent Skills?</summary>

Открытый стандарт расширения AI-агентов (Claude Code, Cursor и др.). Навык загружается в контекст по требованию: агент видит только имя и описание (~100 токенов), а полные инструкции и скрипты подключает когда они нужны.

</details>

## Что умеет

| Операция | Что делает |
|---|---|
| Сборка обработки | XML → EPF/ERF |
| Разборка обработки | EPF/ERF → XML |
| Загрузка конфигурации | XML → база (полностью или отдельные файлы) |
| Выгрузка конфигурации | база → XML (полная или инкрементальная) |
| Загрузка расширения | XML → база |
| Выгрузка расширения | база → XML |
| Сборка файла конфигурации | база → CF |
| Загрузка файла конфигурации | CF → база |
| Сборка файла расширения | база → CFE |
| Сборка CF/CFE из XML (PowerShell) | полная XML-выгрузка → CF или CFE через временную базу |
| Загрузка файла расширения | CFE → база |
| Запуск предприятия | открыть базу в режиме предприятия |
| Запуск конфигуратора | открыть базу в конфигураторе |

## Установка

Скопируйте папку `src/1c-batch` в каталог навыков вашего проекта. Агент с поддержкой Agent Skills обнаружит навык автоматически.

Например, для Claude Code — в `.claude/skills/`.

## Настройка

Создайте в **корне проекта** (или в подпапке `tools\`) файл `.1c-devbase.ps1` по образцу `assets/.1c-devbase.ps1.example`:

```powershell
$ONEC_PATH = "C:\Program Files\1cv8\8.3.24.1467\bin\1cv8.exe"

# Серверная база (приоритет):
$ONEC_SERVER = "server-1c"
$ONEC_BASE   = "erp_dev"

# Или файловая база:
# $ONEC_FILEBASE_PATH = "D:\Bases\MyBase"

$ONEC_USER     = "Администратор"
$ONEC_PASSWORD = ""
```

> Сохраняйте файл в UTF-8 **с BOM** (Windows PowerShell 5.1 читает `.ps1` без BOM как ANSI и портит кириллицу) и добавьте его в `.gitignore` — файл содержит учётные данные.

Для запасных bat-скриптов аналогично создаётся `.1c-devbase.bat` по образцу `assets/.1c-devbase.bat.example`.
